01. Portfolio Management Overview, Client Types & Institutional Matrix

The portfolio management process is an ongoing dynamic framework consisting of three continuous operational phases: Planning (identifying client objectives and constraints, drafting the IPS, forming CME, establishing SAA), Execution (portfolio construction, tactical tilts, and security implementation), and Feedback (performance measurement, attribution, monitoring, and rebalancing).

Defined Benefit (DB) vs Defined Contribution (DC) Pension Plans

Retirement plans represent the largest institutional pools of capital globally. The economic distinction between DB and DC structures dictates liability modeling, investment horizon, and risk tolerance:

  • Defined Benefit (DB) Plans: The plan sponsor (employer) guarantees a defined periodic retirement payout based on a formula (years of service, final average salary). The sponsor bears all investment risk and longevity risk. If portfolio returns underperform or longevity exceeds actuarial projections, the plan incurs an underfunded deficit that the sponsor must remediate via cash contributions. Liabilities are long-term, fixed/inflation-linked cash flows discounted at high-grade corporate bond yields.
  • Defined Contribution (DC) Plans: The plan sponsor makes defined contributions into individual participant accounts. The plan participant (employee) bears all investment risk and longevity risk. The plan sponsor's obligation terminates once contributions are deposited. Asset allocation is directed by the employee based on lifecycle considerations and risk tolerance.

02. Return & Risk Mechanics

Accurate performance measurement requires distinguishing between single-period holding gains, compound multi-period growth, and cash-flow-weighted returns.

Holding Period Return (HPR), Arithmetic & Geometric Returns

Fundamental Return Formulations
$$HPR = \frac{P_t - P_{t-1} + D_t}{P_{t-1}} = \frac{P_t + D_t}{P_{t-1}} - 1$$ $$R_A = \frac{1}{T} \sum_{t=1}^T R_t, \qquad R_G = \left[ \prod_{t=1}^T (1 + R_t) \right]^{1/T} - 1$$ $$R_G \approx R_A - \frac{1}{2} \sigma^2$$ $$\text{Where: } R_A = \text{Arithmetic mean return}, \quad R_G = \text{Geometric compound return}, \quad \sigma^2 = \text{Variance of returns}$$

The geometric mean represents the true compound growth rate of capital per period. It is always less than or equal to the arithmetic mean ($R_G \le R_A$), with the gap widening as return volatility ($\sigma^2$) increases.

Money-Weighted Return (MWR) vs Time-Weighted Return (TWR)

  • Time-Weighted Return (TWR): Measures the compound growth rate of an initial investment over multiple subperiods. By calculating returns across each subperiod separated by external cash flows, TWR isolates investment performance from the timing and magnitude of external deposits and withdrawals. Mandated by GIPS for evaluating investment managers who do not control cash flows.
  • Money-Weighted Return (MWR): The internal rate of return (IRR) that equates the present value of all cash inflows to the present value of all cash outflows. MWR is heavily influenced by the timing and size of external cash injections and withdrawals. If capital is added prior to strong performance, MWR exceeds TWR; if capital is added prior to poor performance, MWR lags TWR.

Worked Numerical Example: MWR vs TWR with Cash Flow Timing

Scenario: An investor opens a portfolio account with an initial outlay of 100,000 USD at $t=0$.

  • At $t=1$, the portfolio value prior to any new cash flows rises to 120,000 USD. The client immediately deposits an additional 50,000 USD into the account, bringing the total portfolio value to 170,000 USD.
  • At $t=2$, the portfolio value falls by 20.0% to 136,000 USD.

Step 1: Compute Subperiod Returns for TWR

$$R_1 = \frac{120,000 - 100,000}{100,000} = +20.00\%$$ $$R_2 = \frac{136,000 - 170,000}{170,000} = -20.00\%$$ $$\text{Annualized TWR} = \sqrt{(1 + R_1)(1 + R_2)} - 1 = \sqrt{(1 + 0.20)(1 - 0.20)} - 1 = \sqrt{0.96} - 1 = 0.9798 - 1 = -2.02\%$$

Step 2: Compute MWR (IRR)

Set the present value of cash inflows equal to cash outflows:

$$\text{Cash Outflows: } t=0: -100,000\text{ USD}; \quad t=1: -50,000\text{ USD}$$ $$\text{Terminal Value: } t=2: +136,000\text{ USD}$$ $$-100,000 - \frac{50,000}{1 + r} + \frac{136,000}{(1 + r)^2} = 0$$ $$100(1+r)^2 + 50(1+r) - 136 = 0$$ $$\text{Let } x = 1+r: \quad 100x^2 + 50x - 136 = 0$$ $$x = \frac{-50 + \sqrt{50^2 - 4(100)(-136)}}{200} = \frac{-50 + \sqrt{2,500 + 54,400}}{200} = \frac{-50 + \sqrt{56,900}}{200} = \frac{-50 + 238.537}{200} = 0.9427$$ $$r = 0.9427 - 1 = -5.73\%$$

Conclusion & Performance Audit: $\text{MWR } (-5.73\%) < \text{TWR } (-2.02\%)$. The investor experienced a worse money-weighted outcome because substantial capital (50,000 USD) was injected immediately before the portfolio suffered a 20.0% downturn, destroying wealth on an enlarged capital base. Evaluating the manager using MWR would unfairly penalize them for client cash-flow timing.

Two-Asset Portfolio Variance and Covariance Mechanics

Portfolio Expected Return and Risk Formulation
$$E(R_p) = w_1 E(R_1) + w_2 E(R_2)$$ $$\sigma_p^2 = w_1^2 \sigma_1^2 + w_2^2 \sigma_2^2 + 2 w_1 w_2 \text{Cov}(R_1, R_2) = w_1^2 \sigma_1^2 + w_2^2 \sigma_2^2 + 2 w_1 w_2 \rho_{1,2} \sigma_1 \sigma_2$$ $$\sigma_p = \sqrt{w_1^2 \sigma_1^2 + w_2^2 \sigma_2^2 + 2 w_1 w_2 \rho_{1,2} \sigma_1 \sigma_2}$$ $$w_1^{\text{min}} = \frac{\sigma_2^2 - \text{Cov}(R_1, R_2)}{\sigma_1^2 + \sigma_2^2 - 2\text{Cov}(R_1, R_2)} \quad (\text{Global Minimum Variance Portfolio Weight})$$

Worked Numerical Example: Two-Asset Risk Diversification Benefit

Parameters:

  • Asset 1 (Equities): $w_1 = 0.60$, $E(R_1) = 10.0\%$, $\sigma_1 = 18.0\%$
  • Asset 2 (Fixed Income): $w_2 = 0.40$, $E(R_2) = 4.5\%$, $\sigma_2 = 7.0\%$
  • Correlation: $\rho_{1,2} = 0.15$

Step 1: Expected Return Calculation

$$E(R_p) = (0.60)(10.0\%) + (0.40)(4.5\%) = 6.00\% + 1.80\% = 7.80\%$$

Step 2: Covariance Calculation

$$\text{Cov}(R_1, R_2) = \rho_{1,2} \sigma_1 \sigma_2 = 0.15 \times 0.18 \times 0.07 = 0.001890$$

Step 3: Variance Component Summation

$$w_1^2 \sigma_1^2 = (0.60)^2 \times (0.18)^2 = 0.36 \times 0.0324 = 0.011664$$ $$w_2^2 \sigma_2^2 = (0.40)^2 \times (0.07)^2 = 0.16 \times 0.0049 = 0.000784$$ $$2 w_1 w_2 \text{Cov}(R_1, R_2) = 2 \times (0.60) \times (0.40) \times 0.001890 = 0.0009072$$ $$\sigma_p^2 = 0.011664 + 0.000784 + 0.0009072 = 0.0133552$$ $$\sigma_p = \sqrt{0.0133552} = 11.56\%$$

Diversification Analysis: The weighted-average standard deviation is $0.60(18.0\%) + 0.40(7.0\%) = 10.80\% + 2.80\% = 13.60\%$. Because $\rho_{1,2} = 0.15 < 1.0$, the actual portfolio risk is $\sigma_p = 11.56\%$. Diversification eliminates $13.60\% - 11.56\% = 2.04\%$ percentage points of annual volatility with zero reduction in expected return.

03. Modern Portfolio Theory & Asset Pricing

Markowitz Modern Portfolio Theory formalizes the mathematical trade-off between risk and expected return, establishing the foundational transition from individual asset characteristics to portfolio equilibrium pricing.

Investor Utility & Indifference Curves

Mean-Variance Utility Function
$$U = E(R) - \frac{1}{2} A \sigma^2$$ $$\text{Where: } U = \text{Expected utility score}, \quad A = \text{Risk-aversion coefficient}, \quad \sigma^2 = \text{Variance of portfolio returns}$$
  • $A > 0$: Risk-Averse (requires higher expected return to accept incremental variance; indifference curves slope upward).
  • $A = 0$: Risk-Neutral (evaluates portfolios purely on expected return, ignoring variance).
  • $A < 0$: Risk-Seeking (willing to sacrifice expected return for higher variance; indifference curves slope downward).

Worked Numerical Example: Utility Ranks Across Differing Risk-Aversion Coefficients

Consider two investment portfolios:

  • Portfolio 1 (Aggressive Equity): $E(R_1) = 11.0\% = 0.11$, $\sigma_1 = 16.0\% = 0.16$ (Variance $\sigma_1^2 = 0.0256$)
  • Portfolio 2 (Conservative Balanced): $E(R_2) = 8.0\% = 0.08$, $\sigma_2 = 8.0\% = 0.08$ (Variance $\sigma_2^2 = 0.0064$)

Evaluation for Investor X (High Risk Aversion, $A = 4$):

$$U_1(A=4) = 0.11 - 0.5(4)(0.0256) = 0.11 - 0.0512 = 0.0588 \quad (5.88\%)$$ $$U_2(A=4) = 0.08 - 0.5(4)(0.0064) = 0.08 - 0.0128 = 0.0672 \quad (6.72\%)$$

Decision: Investor X strictly prefers Portfolio 2 ($U_2 > U_1$).

Evaluation for Investor Y (Moderate Risk Aversion, $A = 2$):

$$U_1(A=2) = 0.11 - 0.5(2)(0.0256) = 0.11 - 0.0256 = 0.0844 \quad (8.44\%)$$ $$U_2(A=2) = 0.08 - 0.5(2)(0.0064) = 0.08 - 0.0064 = 0.0736 \quad (7.36\%)$$

Decision: Investor Y strictly prefers Portfolio 1 ($U_1 > U_2$).

CAL, CML, CAPM & The Security Market Line (SML)

Concept Mathematical Formulation Risk Metric (X-Axis) Applicable Assets Slope Interpretation
Capital Allocation Line (CAL) $$E(R_c) = R_f + \left( \frac{E(R_i) - R_f}{\sigma_i} \right) \sigma_c$$ Total Risk ($\sigma$) Combinations of $R_f$ and any specific risky portfolio $i$ Sharpe Ratio of risky portfolio $i$

Beta Formulation & Systematic vs Unsystematic Decomposition

Systematic Risk & Variance Decomposition
$$\beta_i = \frac{\text{Cov}(R_i, R_m)}{\sigma_m^2} = \frac{\rho_{i,m} \sigma_i \sigma_m}{\sigma_m^2} = \rho_{i,m} \frac{\sigma_i}{\sigma_m}$$ $$\sigma_i^2 = \underbrace{\beta_i^2 \sigma_m^2}_{\text{Systematic (Market) Risk}} + \underbrace{\sigma_{\epsilon,i}^2}_{\text{Unsystematic (Idiosyncratic) Risk}}$$

Performance Metrics & Roy's Safety-First Criterion

Master Performance Ratio Compendium
$$\text{Sharpe Ratio: } SR_p = \frac{R_p - R_f}{\sigma_p}, \qquad \text{Treynor Ratio: } TR_p = \frac{R_p - R_f}{\beta_p}$$ $$\text{Jensen's Alpha: } \alpha_p = R_p - \left[ R_f + \beta_p (R_m - R_f) \right]$$ $$M^2 (\text{Modigliani-Modigliani}): M^2 = (SR_p - SR_m) \sigma_m = R_f + SR_p \sigma_m - R_m$$ $$\text{Roy's Safety-First Ratio: } \text{SFRatio} = \frac{E(R_p) - R_L}{\sigma_p}, \quad P(R_p < R_L) \le N(-\text{SFRatio})$$

04. Portfolio Planning, IPS & Strategic Asset Allocation

The Investment Policy Statement (IPS) acts as the operational constitution governing the client-advisor fiduciary relationship, converting qualitative needs into an executable Strategic Asset Allocation (SAA).

The RRTTLLU Framework

IPS Dimension Key Tenets & Execution Principles Analytical Pitfalls & Rules
Risk Objective (R) Separated into Willingness (psychological/behavioral tolerance) and Ability (financial capacity based on wealth relative to liabilities, horizon, income stability). When willingness and ability conflict, Ability to take risk ALWAYS dominates. An advisor must never expose a portfolio to risk exceeding financial capacity.
Return Objective (R) Distinguishes Desired Return (aspirational) from Required Return (mathematically derived to fund mandatory liabilities, spending rates, inflation, and fees). For institutions: $r_{\text{req}} = \text{Spending Rate} + \text{Inflation} + \text{Investment Expenses}$. Must be evaluated on real vs nominal terms.
Time Horizon (T) Identifies whether horizon is single-stage or multi-stage (divided by major liquidity events, e.g., retirement, business sale, college tuition funding). A longer time horizon directly expands risk capacity, enabling greater allocations to illiquid asset classes and equities.
Tax Considerations (T) Analyzes taxable, tax-deferred, and tax-exempt accounts. Dictates Asset Location: high ordinary income debt in sheltered accounts; equities in taxable accounts. Capital gains realization timing, tax-loss harvesting, and dividend vs capital gain preferential rate differentials.
Liquidity Needs (L) Immediate cash distributions, regular net cash outflows, cash reserves for unforeseen emergencies, and capital call commitments. Liquid assets must be maintained in cash equivalents to prevent forced selling of depressed assets during market drawdowns.
Legal & Regulatory (L) Fiduciary constraints, ERISA qualified plan standards, UPMIFA, prudent investor rule, statutory concentration limits, and trust declarations. Prohibitions on specific asset classes (e.g., short sales, naked derivatives, unrated private placements).
Unique Circumstances (U) Socially Responsible Investing (SRI/ESG) screens, concentrated single-stock equity holdings, non-financial assets (art, real estate), family legacy goals. Concentrated single-stock positions demand hedging (equity collars, prepaid variable forwards) or staged tax-efficient diversification.

Strategic Asset Allocation (SAA) vs Tactical Asset Allocation (TAA)

  • Strategic Asset Allocation (SAA): Establishes the long-term target asset mix designed to satisfy the client's risk-return profile across market cycles. Empirical research shows SAA accounts for over 85%–90% of long-term return variability.
  • Tactical Asset Allocation (TAA): Deliberate short-term adjustments to asset class weights away from SAA targets to exploit short-term valuation anomalies or cyclical macroeconomic dynamics. TAA introduces active risk and tracking error against the policy benchmark.

Portfolio Rebalancing Principles & Corridor Width Determinants

Portfolio drift alters intended risk exposures. Investors utilize Calendar Rebalancing (fixed periodic intervals) or Corridor / Percentage-of-Portfolio Rebalancing (rebalance when weight deviates outside target corridor $w_i \pm \Delta w_i$). Optimal corridor width is governed by six core variables:

Factor Impact on Corridor Width Economic Rationale
Transaction Costs Wider Corridor High trading commissions, bid-ask spreads, and market impact discourage frequent rebalancing.
Risk Tolerance Wider Corridor Clients with higher risk tolerance are comfortable with greater allocation drift from target policy weights.
Asset Class Volatility Narrower Corridor High-volatility assets drift rapidly into excessive risk exposures; tight corridors control downside variance.
Correlation with Portfolio Wider Corridor Assets highly correlated with the broader portfolio do not alter overall portfolio risk substantially when they drift.
Asset Illiquidity Wider Corridor Illiquid private assets cannot be traded frequently without incurring prohibitive liquidation penalties.
Tax Impact (Taxable Accounts) Wider Corridor Rebalancing in taxable accounts triggers taxable capital gains; wider corridors defer tax liabilities.

05. Capital Market Expectations & Macro Risk Premia

Setting long-term expectations for asset class returns, volatilities, and correlations is essential for forming the efficient frontier and designing sound SAA policies.

The Grinold-Kroner Model

Grinold-Kroner Equity Expected Return Model
$$E(R_e) \approx \underbrace{\frac{D_1}{P_0}}_{\text{Dividend Yield}} - \underbrace{\% \Delta S}_{\text{Net Share Repurchases}} + \underbrace{i}_{\text{Expected Inflation}} + \underbrace{g}_{\text{Real Earnings Growth}} + \underbrace{\% \Delta (P/E)}_{\text{Valuation Repricing}}$$ $$\text{Income Return} = \frac{D_1}{P_0} - \% \Delta S, \qquad \text{Nominal Earnings Growth} = i + g, \qquad \text{Repricing} = \% \Delta (P/E)$$

Worked Numerical Example: Step-by-Step Grinold-Kroner Expected Return

Input Estimates for Large-Cap Equity Index:

  • Forward Dividend Yield: $\frac{D_1}{P_0} = 2.40\%$
  • Net Share Issuance / Repurchase: $\% \Delta S = -1.10\%$ (representing an annual net repurchase of 1.10%)
  • Long-term Expected Inflation: $i = 2.25\%$
  • Expected Real GDP / Earnings Growth: $g = 2.75\%$
  • Current Trailing P/E = 22.0, Expected P/E in 10 Years = 20.0

Step 1: Calculate Annualized P/E Repricing Rate

$$\% \Delta (P/E) = \left( \frac{20.0}{22.0} \right)^{1/10} - 1 = (0.90909)^{0.10} - 1 = 0.9905 - 1 = -0.95\%$$

Step 2: Component Aggregation

$$\text{Expected Income Return} = 2.40\% - (-1.10\%) = 2.40\% + 1.10\% = 3.50\%$$ $$\text{Expected Nominal Earnings Growth} = 2.25\% + 2.75\% = 5.00\%$$ $$\text{Expected Repricing Return} = -0.95\%$$ $$E(R_e) = 3.50\% + 5.00\% - 0.95\% = 7.55\%$$

The Singer-Terhaar Model

Singer-Terhaar International Asset Pricing with Partial Integration
$$ERP_i = \phi \cdot ERP_{i,\text{integrated}} + (1 - \phi) \cdot ERP_{i,\text{segmented}} + \text{Illiquidity Premium}$$ $$ERP_{i,\text{integrated}} = \beta_{i,G} \cdot ERP_G = \rho_{i,G} \cdot \sigma_i \cdot \left( \frac{ERP_G}{\sigma_G} \right) = \rho_{i,G} \cdot \sigma_i \cdot SR_G$$ $$ERP_{i,\text{segmented}} = \sigma_i \cdot \left( \frac{ERP_i}{\sigma_i} \right) = \sigma_i \cdot SR_i \quad (\text{where } SR_i \approx SR_G)$$ $$E(R_i) = R_f + ERP_i$$

Worked Numerical Example: Singer-Terhaar Emerging Market Equity Premium

Market Inputs:

  • Risk-free rate: $R_f = 3.50\%$
  • Global Investable Market: Volatility $\sigma_G = 16.0\%$, Global Risk Premium $ERP_G = 4.80\%$ $\implies SR_G = \frac{4.80\%}{16.0\%} = 0.30$
  • Target Emerging Market X: Volatility $\sigma_X = 24.0\%$, Correlation with Global $\rho_{X,G} = 0.55$
  • Degree of Global Integration: $\phi = 0.70$ (70% integrated, 30% segmented)
  • Illiquidity Premium for Market X: $0.75\%$

Step 1: Compute Fully Integrated Risk Premium

$$ERP_{X,\text{integrated}} = \rho_{X,G} \times \sigma_X \times SR_G = 0.55 \times 24.0\% \times 0.30 = 3.96\%$$

Step 2: Compute Fully Segmented Risk Premium

$$ERP_{X,\text{segmented}} = \sigma_X \times SR_G = 24.0\% \times 0.30 = 7.20\%$$

Step 3: Calculate Blended Risk Premium and Total Expected Return

$$ERP_X = (0.70 \times 3.96\%) + (0.30 \times 7.20\%) + 0.75\% = 2.772\% + 2.160\% + 0.75\% = 5.682\%$$ $$E(R_X) = R_f + ERP_X = 3.50\% + 5.682\% = 9.182\% \approx 9.18\%$$

The Taylor Rule for Central Bank Policy Rate Determination

Taylor Rule Policy Rate Formulation
$$i^* = r_{\text{neutral}} + \pi + 0.5(\pi - \pi^*) + 0.5(y - y^*)$$ $$\text{Where: } i^* = \text{Target central bank policy rate}, \quad r_{\text{neutral}} = \text{Neutral real policy rate}, \quad \pi = \text{Current inflation rate}$$ $$\pi^* = \text{Central bank inflation target}, \quad y - y^* = \text{Output gap (actual vs potential real GDP in percent)}$$

Policy Implication: When actual inflation exceeds the target ($\pi > \pi^*$) or output exceeds potential ($y > y^*$), the Taylor Rule prescribes an elevated policy rate to cool aggregate demand. If current rates are below $i^*$, monetary authorities will likely hike rates, inducing yield curve flattening and compressed equity valuation multiples.

06. Analysis of Active Portfolio Management & The Fundamental Law

Active portfolio management seeks to generate positive risk-adjusted excess returns over a benchmark through superior forecasting skill, breadth of independent decisions, and unconstrained implementation.

Active Return, Tracking Error & Information Ratio

Core Active Risk & Return Metrics
$$R_A = R_P - R_B \quad (\text{Active Return})$$ $$\sigma_A = \sqrt{\frac{1}{T-1} \sum_{t=1}^T (R_{A,t} - \bar{R}_A)^2} \quad (\text{Tracking Error / Active Risk})$$ $$IR = \frac{\bar{R}_A}{\sigma_A} = \frac{R_P - R_B}{\sigma_A} \quad (\text{Information Ratio})$$

Grinold's Fundamental Law of Active Management

The Fundamental Law (Unconstrained vs Constrained)
$$\text{Unconstrained: } IR = IC \times \sqrt{BR}, \qquad E(R_A) = IC \times \sqrt{BR} \times \sigma_A$$ $$\text{Full (Constrained): } IR = TC \times IC \times \sqrt{BR}, \qquad E(R_A) = TC \times IC \times \sqrt{BR} \times \sigma_A$$ $$\sigma_A^* = \frac{IR}{SR_B} \cdot \sigma_B = TC \cdot \frac{IC \cdot \sqrt{BR}}{SR_B} \cdot \sigma_B \quad (\text{Optimal Active Risk})$$ $$SR_P^2 = SR_B^2 + IR^2 = SR_B^2 + (TC \times IC \times \sqrt{BR})^2 \quad (\text{Total Sharpe Expansion})$$
  • Information Coefficient ($IC$): Ex-ante forecast skill. Correlation between forecasted and realized active returns ($IC = \text{Corr}(\hat{R}_A, R_A)$). From hit rate $p$: $IC = 2p - 1$.
  • Transfer Coefficient ($TC$): Ability to translate unconstrained active bets into actual portfolio holdings ($TC = \text{Corr}(\Delta w_i, \Delta w_i^*)$). $TC = 1.0$ for unconstrained portfolios; $TC < 1.0$ for long-only or benchmark-constrained portfolios.
  • Breadth ($BR$): Number of independent return forecasts executed per year.

Worked Numerical Example: The Fundamental Law, Optimal Active Risk & Sharpe Ratio

Parameters:

  • Benchmark: Sharpe Ratio $SR_B = 0.50$, Standard Deviation $\sigma_B = 14.0\%$
  • Active Manager: Universe of 100 stocks evaluated quarterly ($BR = 100 \times 4 = 400$ independent decisions per year)
  • Skill: Information Coefficient $IC = 0.05$
  • Implementation Constraints: Long-only mandate reduces Transfer Coefficient to $TC = 0.70$

Step 1: Calculate Achievable Information Ratio ($IR$)

$$IR = TC \times IC \times \sqrt{BR} = 0.70 \times 0.05 \times \sqrt{400} = 0.70 \times 0.05 \times 20 = 0.70$$

Step 2: Compute Optimal Active Risk ($\sigma_A^*$)

$$\sigma_A^* = \frac{IR}{SR_B} \times \sigma_B = \frac{0.70}{0.50} \times 14.0\% = 1.40 \times 14.0\% = 19.60\%$$

Step 3: Calculate Expected Active Return ($E(R_A)$)

$$E(R_A) = IR \times \sigma_A^* = 0.70 \times 19.60\% = 13.72\%$$

Step 4: Compute Total Maximized Portfolio Sharpe Ratio ($SR_P$)

$$SR_P = \sqrt{SR_B^2 + IR^2} = \sqrt{(0.50)^2 + (0.70)^2} = \sqrt{0.25 + 0.49} = \sqrt{0.74} = 0.8602$$

07. Multifactor Risk Models & Factor Attribution

Multifactor models decompose asset returns and risks into common systematic factor exposures and asset-specific idiosyncratic noise.

Three Types of Multifactor Models

  • Macroeconomic Factor Models: Factor sensitivities are estimated via time-series regression against unexpected macroeconomic surprises: $$R_i = E(R_i) + b_{i,1} F_1^{\text{surprise}} + b_{i,2} F_2^{\text{surprise}} + \dots + \epsilon_i$$ Examples: Inflation surprise, GDP growth surprise, credit default spread shifts.
  • Fundamental Factor Models: Factor sensitivities are standardized firm attributes (e.g., P/E, Market Cap, Momentum), and factor returns are estimated via cross-sectional regression: $$R_i = a_i + b_{i,1} F_1 + b_{i,2} F_2 + \dots + \epsilon_i, \qquad b_{i,k} = \frac{X_{i,k} - \bar{X}_k}{\sigma_{X_k}}$$
  • Statistical Factor Models: Factor portfolios are extracted mathematically using Principal Component Analysis (PCA) or maximum likelihood factor analysis. Maximize explained return variance but lack direct economic interpretability.

Carhart 4-Factor & Fama-French 5-Factor Models

Empirical Factor Pricing Models
$$\text{Carhart 4-Factor: } E(R_i) - R_f = \beta_{i,MKT} (R_m - R_f) + \beta_{i,SMB} SMB + \beta_{i,HML} HML + \beta_{i,WML} WML$$ $$\text{Fama-French 5-Factor: } E(R_i) - R_f = \beta_{i,MKT} (R_m - R_f) + \beta_{i,SMB} SMB + \beta_{i,HML} HML + \beta_{i,RMW} RMW + \beta_{i,CMA} CMA$$ $$\text{Where: } SMB = \text{Small Minus Big}, \quad HML = \text{High Minus Low (Book-to-Market)}, \quad WML = \text{Winners Minus Losers (Momentum)}$$ $$RMW = \text{Robust Minus Weak Profitability}, \quad CMA = \text{Conservative Minus Aggressive Investment}$$

Active Risk Decomposition: Factor Risk vs Specific Risk

Active Variance Decomposition
$$\sigma_A^2 = \underbrace{\sum_{j=1}^K \sum_{k=1}^K \Delta \beta_j \Delta \beta_k \text{Cov}(F_j, F_k)}_{\text{Active Factor Risk (Systematic)}} + \underbrace{\sum_{i=1}^N \Delta w_i^2 \sigma_{\epsilon,i}^2}_{\text{Active Specific Risk (Idiosyncratic)}}$$ $$\text{Where: } \Delta \beta_k = \beta_{P,k} - \beta_{B,k} \quad (\text{Active Factor Sensitivity}), \quad \Delta w_i = w_{P,i} - w_{B,i} \quad (\text{Active Asset Weight})$$

Worked Numerical Example: Factor vs Specific Active Risk Decomposition

A portfolio manager holds active exposures to two factors: Market ($\Delta eta_1 = +0.15$) and Size ($\Delta eta_2 = +0.25$).

  • Factor Volatilities: $\sigma_{F1} = 15.0\%$, $\sigma_{F2} = 8.0\%$; Factor Correlation: $\rho_{1,2} = 0.20$
  • Active Specific Risk (from security selection): $\sigma_{\epsilon,A} = 2.80\%$ (Specific Variance $= 2.80^2 = 7.84$)

Step 1: Compute Factor Covariance

$$\text{Cov}(F_1, F_2) = \rho_{1,2} \sigma_{F1} \sigma_{F2} = 0.20 \times 15.0 \times 8.0 = 24.0$$

Step 2: Compute Active Factor Variance

$$\text{Var}(F_1 \text{ component}) = (\Delta \beta_1)^2 \sigma_{F1}^2 = (0.15)^2 \times (15.0)^2 = 0.0225 \times 225 = 5.0625$$ $$\text{Var}(F_2 \text{ component}) = (\Delta \beta_2)^2 \sigma_{F2}^2 = (0.25)^2 \times (8.0)^2 = 0.0625 \times 64 = 4.0000$$ $$\text{Covariance component} = 2 \Delta \beta_1 \Delta \beta_2 \text{Cov}(F_1, F_2) = 2 \times 0.15 \times 0.25 \times 24.0 = 1.8000$$ $$\text{Active Factor Variance} = 5.0625 + 4.0000 + 1.8000 = 10.8625$$

Step 3: Total Active Variance and Tracking Error

$$\sigma_A^2 = \text{Active Factor Variance} + \text{Active Specific Variance} = 10.8625 + 7.8400 = 18.7025$$ $$\sigma_A = \sqrt{18.7025} = 4.32\%$$

Attribution Breakdown: Active factor risk accounts for $\frac{10.8625}{18.7025} = 58.08\%$ of total active variance, while active specific risk accounts for $\frac{7.8400}{18.7025} = 41.92\%$.

08. ETFs, Algorithmic Execution & Implementation Shortfall

Trade execution represents the critical bridge between investment decision-making and realized portfolio returns, demanding precise cost decomposition and execution algorithm selection.

ETF Creation / Redemption & Arbitrage Bands

  • Authorized Participants (APs) & In-Kind Mechanism: APs create and redeem ETF shares in large blocks (Creation Units) directly with the ETF fund sponsor using in-kind transfers of underlying security baskets. Because securities are transferred in-kind rather than sold for cash, capital gains are not realized within the fund, preserving structural tax efficiency.
  • Arbitrage Bands: When ETF market prices deviate from Net Asset Value (NAV), APs arbitrage the spread:
    • If ETF trades at a premium: AP buys underlying basket, delivers to sponsor for new ETF shares, sells ETF shares in open market.
    • If ETF trades at a discount: AP buys undervalued ETF shares, redeems with sponsor for underlying basket, sells underlying securities in open market.
    Arbitrage bands are bounded by AP transaction costs (bid-ask spread of underlying securities + creation/redemption fees + hedging costs).
  • Tracking Difference vs Tracking Error:
    • Tracking Difference ($TD$): Holding period return differential: $TD = R_{\text{ETF}} - R_{\text{Benchmark}}$. Primary drivers: expense ratio, cash drag, securities lending revenue.
    • Tracking Error ($TE$): Standard deviation of excess returns over time: $TE = \text{Std}(R_{\text{ETF}} - R_{\text{Benchmark}})$.

Algorithmic Trade Execution Strategies

Algorithm Type Execution Mechanism Optimal Market Environment
Volume-Weighted Average Price (VWAP) Slices parent order over the trading day in proportion to historical intraday volume distributions. Liquid equities, trade size is small proportion of Average Daily Volume (ADV < 10%), no extreme urgency.
Time-Weighted Average Price (TWAP) Slices parent order evenly across equal time intervals throughout the trading session. Markets with erratic or non-standard volume distributions where historical volume curves are unreliable.
Percentage of Volume (POV) Participates dynamically as a specified target percentage of continuous market volume (e.g., 15% of volume). Orders where manager wants execution rate to automatically accelerate during volume spikes and pause during lulls.
Implementation Shortfall (IS) Algos Dynamically balances market impact costs (accelerated trading) against price slippage and timing risk (slower trading). High-urgency trades, orders with high alpha decay, or orders where market momentum threatens to move price away.

Implementation Shortfall 4-Component Cost Decomposition

Implementation Shortfall Mathematical Framework
$$\text{Paper Portfolio Return: } \Pi_{\text{Paper}} = S \times P_n - S \times P_d$$ $$\text{Real Portfolio Return: } \Pi_{\text{Real}} = \sum s_j P_n - \sum s_j p_j - \text{Fees}$$ $$\text{Total IS} = \Pi_{\text{Paper}} - \Pi_{\text{Real}} = \text{Delay Cost} + \text{Trading Cost} + \text{Opportunity Cost} + \text{Explicit Fees}$$

For a BUY order of $S$ shares with decision price $P_d$, arrival price $P_0$, executed prices $p_j$ for $S_E = \sum s_j$ shares, cancelled unexecuted shares $S_U = S - S_E$, and cancellation price $P_{\text{cancel}}$:

Component Formula (BUY Order) Economic Representation
1. Delay Cost (Slippage) $$(P_0 - P_d) \times S_E$$ Price drift between the PM's investment decision and order arrival at the market for executed shares.
2. Trading Cost (Market Impact) $$\sum_{j} (p_j - P_0) \times s_j$$ Price movement caused by executing the trade relative to the market arrival price.
3. Opportunity Cost (Unexecuted) $$(P_{\text{cancel}} - P_d) \times S_U$$ Return foregone on unfilled shares due to adverse price movements prior to order cancellation.
4. Explicit Costs $$\text{Broker commissions, exchange fees, taxes}$$ Direct cash fees incurred during execution.

Note on Combined Execution Cost: $\text{Delay Cost} + \text{Trading Cost} = \sum_{j} (p_j - P_d) \times s_j$.

Worked Numerical Example: Complete Step-by-Step Implementation Shortfall Audit

Order Scenario:

  • On Monday, a portfolio manager decides to purchase $S = 10,000$ shares of Stock XYZ. The decision price is $P_d = 50.00\text{ USD}$.
  • The theoretical paper portfolio investment is $10,000 \times 50.00\text{ USD} = 500,000\text{ USD}$.
  • The order is released to the trading desk on Tuesday morning when the market opens at an arrival price of $P_0 = 50.50\text{ USD}$.
  • Execution Day 1: 6,000 shares are executed at an average price of $p_1 = 51.20\text{ USD}$.
  • Execution Day 2: 2,000 shares are executed at an average price of $p_2 = 52.00\text{ USD}$.
  • Total executed shares: $S_E = 6,000 + 2,000 = 8,000$ shares.
  • At the close of Day 2, the remaining $S_U = 2,000$ shares are cancelled when the market price is $P_{\text{cancel}} = 53.00\text{ USD}$.
  • Total explicit commissions and fees: 1,200 USD.

Step-by-Step Component Calculations:

  1. Delay Cost (Arrival Slippage on Executed Shares): $$(P_0 - P_d) \times S_E = (50.50\text{ USD} - 50.00\text{ USD}) \times 8,000 = 0.50\text{ USD} \times 8,000 = 4,000\text{ USD}$$ $$\text{In basis points: } \frac{4,000\text{ USD}}{500,000\text{ USD}} \times 10,000 = 80.0\text{ bps}$$
  2. Trading Cost (Market Impact on Executed Shares): $$\sum (p_j - P_0) s_j = (51.20 - 50.50) \times 6,000 + (52.00 - 50.50) \times 2,000 = (0.70 \times 6,000) + (1.50 \times 2,000) = 4,200\text{ USD} + 3,000\text{ USD} = 7,200\text{ USD}$$ $$\text{In basis points: } \frac{7,200\text{ USD}}{500,000\text{ USD}} \times 10,000 = 144.0\text{ bps}$$ (Check total execution cost: $4,000 + 7,200 = 11,200\text{ USD}$, which matches $\sum (p_j - P_d) s_j = (51.20-50)\times 6,000 + (52.00-50)\times 2,000 = 7,200 + 4,000 = 11,200\text{ USD}$ or $224.0\text{ bps}$.)
  3. Opportunity Cost (Unexecuted Shares): $$(P_{\text{cancel}} - P_d) \times S_U = (53.00\text{ USD} - 50.00\text{ USD}) \times 2,000 = 3.00\text{ USD} \times 2,000 = 6,000\text{ USD}$$ $$\text{In basis points: } \frac{6,000\text{ USD}}{500,000\text{ USD}} \times 10,000 = 120.0\text{ bps}$$
  4. Explicit Costs: $$\text{Fees} = 1,200\text{ USD}$$ $$\text{In basis points: } \frac{1,200\text{ USD}}{500,000\text{ USD}} \times 10,000 = 24.0\text{ bps}$$
  5. Total Implementation Shortfall: $$\text{Total IS} = 4,000\text{ USD} + 7,200\text{ USD} + 6,000\text{ USD} + 1,200\text{ USD} = 18,400\text{ USD}$$ $$\text{IS (bps)} = \frac{18,400\text{ USD}}{500,000\text{ USD}} \times 10,000 = 368.0\text{ bps} \quad (3.68\%)$$

Consolidated, rigorous formula sheet mapping all key mathematical equations across Level 1 and Level 2 Portfolio Management syllabus.

Return Mechanics Geometric Return Approx $$R_G \approx R_A - \frac{1}{2} \sigma^2$$ $R_A$: Arithmetic mean, $\sigma^2$: Variance. Volatility creates return drag.
Two-Asset Risk Portfolio Variance $$\sigma_p^2 = w_1^2 \sigma_1^2 + w_2^2 \sigma_2^2 + 2 w_1 w_2 \rho_{1,2} \sigma_1 \sigma_2$$ Diversification benefit maximizes as correlation $\rho_{1,2} \to -1$.

Asset Pricing Capital Market Line $$E(R_p) = R_f + \left( \frac{E(R_m) - R_f}{\sigma_m} \right) \sigma_p$$ Applies strictly to efficient portfolios; slope is Market Sharpe Ratio.
Systematic Risk Asset Beta ($\beta_i$) $$\beta_i = \frac{\text{Cov}(R_i, R_m)}{\sigma_m^2} = \rho_{i,m} \frac{\sigma_i}{\sigma_m}$$ Measures sensitivity of asset returns to market returns.
CAPM Security Market Line $$E(R_i) = R_f + \beta_i \left[ E(R_m) - R_f \right]$$ Applies to all individual assets; assets above SML have $\alpha > 0$.

Performance Treynor Ratio $$TR_p = \frac{R_p - R_f}{\beta_p}$$ Measures excess return per unit of systematic risk $\beta_p$.
Performance Jensen's Alpha $$\alpha_p = R_p - \left[ R_f + \beta_p (R_m - R_f) \right]$$ Abnormal return relative to CAPM benchmark hurdle.

CME Singer-Terhaar Model $$ERP_i = \phi (\rho_{i,G} \sigma_i SR_G) + (1-\phi)(\sigma_i SR_G) + \text{Prem}_{\text{illiquid}}$$ $\phi$: Integration degree. Blends integrated and segmented risk premia.
Macro Policy Taylor Rule $$i^* = r_{\text{neutral}} + \pi + 0.5(\pi - \pi^*) + 0.5(y - y^*)$$ Prescribes central bank target rate based on inflation and output gap.
